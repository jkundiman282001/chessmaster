# Chess Piece Assets Folder

Place your custom chess piece images in this folder!

## Supported Formats
- **SVG** (recommended for sharp, crisp rendering at any screen resolution): `.svg`
- **PNG** (transparent background recommended): `.png`
- **WebP**: `.webp`

---

## File Naming Convention

Name your piece image files using the standard chess notation:

### White Pieces
| Piece | Filename |
| :--- | :--- |
| **White Pawn** | `w_p.svg` (or `w_p.png`, `wP.svg`, `wP.png`) |
| **White Knight** | `w_n.svg` (or `w_n.png`, `wN.svg`, `wN.png`) |
| **White Bishop** | `w_b.svg` (or `w_b.png`, `wB.svg`, `wB.png`) |
| **White Rook** | `w_r.svg` (or `w_r.png`, `wR.svg`, `wR.png`) |
| **White Queen** | `w_q.svg` (or `w_q.png`, `wQ.svg`, `wQ.png`) |
| **White King** | `w_k.svg` (or `w_k.png`, `wK.svg`, `wK.png`) |

### Black Pieces
| Piece | Filename |
| :--- | :--- |
| **Black Pawn** | `b_p.svg` (or `b_p.png`, `bP.svg`, `bP.png`) |
| **Black Knight** | `b_n.svg` (or `b_n.png`, `bN.svg`, `bN.png`) |
| **Black Bishop** | `b_b.svg` (or `b_b.png`, `bB.svg`, `bB.png`) |
| **Black Rook** | `b_r.svg` (or `b_r.png`, `bR.svg`, `bR.png`) |
| **Black Queen** | `b_q.svg` (or `b_q.png`, `bQ.svg`, `bQ.png`) |
| **Black King** | `b_k.svg` (or `b_k.png`, `bK.svg`, `bK.png`) |
