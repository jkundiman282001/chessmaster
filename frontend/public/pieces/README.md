# Chess Piece Assets Folder

Default and custom chess piece image sets for the game.

## Default Game Piece Sets (Active)
The game by default loads pieces from:
- `frontend/public/pieces/White Classic/`
- `frontend/public/pieces/Black Classic/`

### White Classic (`frontend/public/pieces/White Classic/`)

## Supported Formats
- **PNG** (transparent RGBA background recommended): `.png`
- **SVG** (vector): `.svg`
- **WebP**: `.webp`
